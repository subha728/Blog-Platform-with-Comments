# Blog Platform with Comments

A full-stack blogging application where users can register, log in, create blog posts, edit and delete posts, and interact through comments.

## Features

* User Registration & Login
* Create, Read, Update, and Delete Posts (CRUD)
* Add and View Comments
* Search Posts
* Responsive and User-Friendly Interface
* MongoDB Database Integration

## Tech Stack

**Frontend**

* HTML
* CSS
* JavaScript

**Backend**

* Node.js
* Express.js

**Database**

* MongoDB Atlas
* Mongoose
